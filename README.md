# Student Management System API

Spring Boot backend with JWT authentication and role-based access control.

## 🚀 Features
- JWT Authentication
- Role & Permission-based authorization
- CRUD APIs (Student, Course, Enrollment, Attendance, Exams, Marks)
- Swagger UI for API testing

## 🛠 Tech Stack
- Spring Boot
- Spring Security
- JPA / Hibernate
- MySQL
- JWT

## ▶️ Run Locally

1. Clone the repository  
2. Configure JWT secret  
   - `application.properties` contains a dummy value  
   - Replace it with your own for proper usage  
3. Run the application  

## 📄 API Documentation

Swagger UI:
http://localhost:8080/swagger-ui/index.html

## ⚠️ Notes
- This is an early-stage prototype  
- For authenticated endpoints, use JWT (via Postman)
